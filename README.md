# Khadim - Site Sénégal Invest

Ce site présente les opportunités d'investissement au Sénégal.

## Déploiement

Le site est déployé sur GitHub Pages à l'adresse : https://diop10a-wq.github.io/khadim

Pour déployer :
1. Pousser le code vers le dépôt GitHub.
2. Aller dans Settings > Pages, sélectionner la branche main comme source.
3. Le site sera disponible à https://diop10a-wq.github.io/khadim

Si vous voulez l'URL https://diop10a-wq.github.io/senegal-invest, renommez le dépôt en "senegal-invest" sur GitHub.
